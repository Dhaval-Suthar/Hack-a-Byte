# Games Documentation

## HACK.EXE: A Virtual Windows 95 Hacking Game

### Game Premise & Core Experience

HACK.EXE transports players to a meticulously recreated Windows 95 desktop, acting as their primary interface. Every interaction, from opening applications to receiving mission updates, happens within this virtual OS. The game combines point-and-click exploration with puzzle-solving mini-games that are narratively justified as hacking attempts. Success relies not just on puzzle mastery but also on understanding the subtle clues hidden within the Win95 environment itself.

### Story Campaign Chapters

#### Prologue: The Awakening
- **Objective**: Familiarize with the virtual Windows 95 environment
- **Experience**: Tutorial-like introduction to basic OS navigation
- **Setting**: Inheriting a mysterious hacker's computer system

#### Chapter 1: Breaking into Basics
- **Objective**: Recover a forgotten password from an old ZIP file
- **Mini-Game**: Brute Force Alphabets
- **Challenge**: Rapidly cycle through characters to crack password sequences

#### Chapter 2: Network Traces
- **Objective**: Identify the virtual location (IP address) of a rival hacker
- **Mini-Game**: IP Finder
- **Challenge**: Correlate log file data with network map to locate target

#### Chapter 3: Firewall Follies
- **Objective**: Navigate and bypass the target machine's firewalls
- **Mini-Game**: Number Jumping Selection
- **Challenge**: Select numbers in specific sequences to bypass security protocols

#### Chapter 4: The Web of Data
- **Objective**: Restore fragmented neural net data for intelligence
- **Mini-Game**: Untangle Neural Network
- **Challenge**: Drag-and-drop nodes to eliminate line intersections

#### Chapter 5: Locked Out
- **Objective**: Bypass a high-level encrypted secure vault with biometric lock
- **Mini-Game**: Fingerprint Hack
- **Challenge**: Reconstruct fingerprint patterns from fragments

#### Chapter 6: The Countermeasure
- **Objective**: Quickly disable ShadowByte's remote wipe countdown
- **Mini-Game**: Quick Event Presser (Final Test)
- **Challenge**: Race against time with rapid input sequences

#### Epilogue: Wired into the Mainframe
- **Outcome**: Full initiation into the hacker underground
- **Unlock**: New Game+ / Endless Mode for continued gameplay

### Atmosphere & Immersion Features

#### Authentic Windows 95 Experience
- Pixel-perfect recreation of Win95 UI elements
- Classic icons, window borders, cursors, and system fonts
- Period-accurate sound effects and system chimes

#### Narrative Delivery Methods
- **Notepad Files**: Cryptic clues and backstory fragments
- **Fake Chatroom Pop-ups**: Primary communication with anonymous contacts
- **ReadMe.txt Files**: Hidden lore and world-building details
- **System Sounds**: Authentic PC hums, clicks, and error beeps

#### Easter Eggs & References
- Nostalgic 90s tech culture references
- Hidden desktop shortcuts and fake drive contents
- Humorous file names and system messages

### New Game+ Features
- Persistent "Contracts" application on desktop
- Randomly generated contract jobs using all mini-games
- Scalable difficulty with higher rewards for complex challenges
- Endless replayability beyond main story completion
