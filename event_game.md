# CryptoHeist: Digital Warfare
## Complete Game Concept Summary

### Game Overview
**CryptoHeist: Digital Warfare** is a competitive PvP team-based digital heist game where teams of 1-4 players battle to accumulate the highest bitcoin balance while defending their own cryptocurrency wallets. The game features unified mechanics across mobile HackDroid devices and Windows 95/XP desktop interfaces, with adaptive difficulty based on team tech knowledge.

---

## Event Flow & Player Journey

### 1. Team Registration Process
Teams arrive at the event and scan a QR code that takes them to the event website. They register their team, choose their preferred platform (mobile or desktop), and pay the entrance fee. Upon successful registration, they receive via email:
- A unique team wallet address
- Private key for wallet access  
- Access code (valid for 4 uses - one per team member)

### 2. Device Entry & Setup
Teams use their access code to enter the play space on their chosen device (one shared device per team). The device starts in a "secureless" state, emphasizing the need for immediate defensive action. All four team members gather around the single device to collaborate.

### 3. Tech Knowledge Assessment
Before gameplay begins, teams take a quick 60-second tech literacy quiz covering:
- Security basics (passwords, encryption)
- Networking fundamentals (VPNs, firewalls)
- Malware identification
- System management (restart, shutdown)
- Web safety awareness
- Strategic decision-making

Based on results, teams are classified as Novice, Intermediate, or Advanced, which determines UI complexity and gameplay mechanics.

## Adaptive Difficulty System

The game automatically adjusts complexity based on the pre-game tech assessment:

### Interface Complexity
- **Novice:** Single-window interfaces, large buttons, color-coded status indicators
- **Intermediate:** Multi-tabbed interfaces, moderate complexity, tooltips available
- **Advanced:** Multi-window environments, keyboard shortcuts, minimal hand-holding

### Gameplay Mechanics
- **Novice:** Longer action cooldowns, clearer success indicators, guided decision-making
- **Intermediate:** Balanced complexity, some advanced options, moderate timing requirements
- **Advanced:** Full feature sets, precise timing requirements, complex strategy options

### Real-Time Adjustments
The game monitors team performance and provides subtle assistance if teams are overwhelmed, while introducing additional challenges for teams that are dominating.

## Game Mechanics & Flow

### Match Structure (20 minutes total)
1. **Setup Phase (2 minutes):** Role selection, initial security setup, strategy planning
2. **Active Phase (15 minutes):** Live PvP action with all roles operating simultaneously
3. **Resolution Phase (3 minutes):** Final scoring, statistics review, winner determination

### Victory Conditions
- **Primary:** Team with highest bitcoin balance wins
- **Bonus Scoring:** Perfect defense, flawless attacks, efficient extraction, master coordination

### Platform Features
- **Mobile (HackDroid):** Touch-optimized gestures, haptic feedback, voice chat integration
- **Desktop (Windows 95/XP):** Multi-window interface, keyboard shortcuts, detailed analytics
