## What Was Created

### For HackPhone (Mobile)
✅ **BlackMart Mobile App** - App Store styled malware marketplace

- Home screen icon integration

## Features Implemented

### 🛒 Malware Catalog (Both Platforms)
- **9 Different Malware Types** across 3 categories
- **Virus** (requires MAC address): SysTrojan Pro, StealthViral, DataMiner X
- **Worm** (requires IP address): EmailSpread Pro, NetCrawler, SocialHook  
- **Ransomware** (requires domain): CryptoLocker Elite, FakeBank Portal, SystemLock Pro

### 🎯 Core Functionality
- **Browse & Search** malware catalog
- **Category Filtering** by malware type
- **Purchase System** with simulated transactions
- **Deployment System** with parameter requirements
- **Educational Warnings** and safety disclaimers

### 🎨 Platform-Specific Design
- **Win95 Style** (HackBook E95): Authentic Windows 95 UI elements
- **iOS Style** (HackPhone): App Store-inspired mobile interface

## How to Access

### HackBook E95
1. Double-click BlackMart desktop icon, OR
2. Start Menu → Programs → BlackMart

### HackPhone  
1. Swipe through home screen pages to find BlackMart icon
2. Tap to launch the mobile app
