# Number Jumping Selection Mini-Game

## Overview
The Number Jumping Selection mini-game represents firewall bypass attempts through strategic number selection. Players must identify and select numbers in specific sequences or patterns to create "data pipelines" that allow information to sneak through security protocols.

## Gameplay Mechanics

### Grid-Based Interface
- **Number Grid**: Matrix of numbers representing ports, packet sizes, or byte values
- **Selection System**: Click-based number choosing with visual feedback
- **Pipeline Visualization**: Illuminated segments showing successful data pathways
- **Pattern Requirements**: Specific sequences needed to bypass security

### Core Selection Logic
1. **Pattern Recognition**: Identify required number sequences (prime, ascending, multiples)
2. **Path Planning**: Visualize optimal routes across the grid
3. **Sequential Selection**: Choose numbers in correct order to build pipeline
4. **Security Bypass**: Complete patterns unlock firewall segments

### Pattern Types

#### Mathematical Sequences
- **Prime Numbers**: Select only prime values in ascending order
- **Fibonacci Series**: Follow the mathematical progression
- **Multiples**: Choose numbers divisible by specific values
- **Perfect Squares**: Identify and select squared integers

#### Geometric Patterns
- **L-Shapes**: Create angular pathways across the grid
- **Diagonal Lines**: Straight paths from corner to corner
- **Spiral Patterns**: Curved routes following circular logic
- **Cross Formations**: Intersecting perpendicular lines

#### Logical Progressions
- **Ascending Order**: Select numbers from lowest to highest
- **Descending Chains**: Choose values in decreasing sequence
- **Even/Odd Alternation**: Switch between number types
- **Binary Representation**: Follow 0/1 patterns in decimal form

## Difficulty Scaling

### Basic Firewall Level
- **Small Grid**: 4x4 or 5x5 number matrix
- **Simple Patterns**: Basic ascending/descending sequences
- **Clear Instructions**: Explicit pattern requirements displayed
- **Generous Timing**: No time pressure for selections
- **Visual Hints**: Subtle highlighting of correct path options

### Intermediate Security
- **Medium Grid**: 6x6 or 7x7 number arrangement
- **Mixed Patterns**: Combination of mathematical and geometric requirements
- **Partial Instructions**: Some pattern rules must be deduced
- **Moderate Timing**: Reasonable time limits for completion
- **Trap Numbers**: Incorrect choices that trigger minor penalties

### Advanced Encryption
- **Large Grid**: 8x8 or larger complex matrices
- **Complex Patterns**: Multi-layered sequence requirements
- **Hidden Rules**: Pattern logic must be discovered through experimentation
- **Time Pressure**: Strict deadlines for firewall bypass
- **Alarm Triggers**: Specific numbers that immediately fail the attempt

## Success and Failure Mechanics

### Victory Conditions
- **Complete Pipeline**: Successfully illuminate entire data pathway
- **Pattern Completion**: Fulfill all sequence requirements within time limit
- **Stealth Success**: Bypass without triggering security alarms
- **Efficiency Bonus**: Complete with minimal number of selections

### Failure States
- **Port Blocked**: Error message for incorrect number selection
- **Sequence Reset**: Pattern progress lost, requiring restart
- **Alarm Triggered**: Immediate failure from selecting trap numbers
- **Timeout Failure**: Unable to complete pattern within time constraints

### Progressive Penalties
- **Warning Phase**: First mistake generates cautionary message
- **Timeout Addition**: Subsequent errors reduce available time
- **Pattern Scramble**: Multiple failures randomize grid layout
- **Security Escalation**: Repeated attempts increase difficulty
