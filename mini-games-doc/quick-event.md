# Quick Event Presser Mini-Game

## Overview
The Quick Event Presser mini-game is the ultimate test of reflexes and ability to react under extreme pressure. Players must rapidly execute a series of commands to prevent a catastrophic system wipe while the virtual Windows 95 environment spirals into chaos.

## Gameplay Mechanics

### Rapid Response System
- **Pop-up Commands**: Clunky Win95-style dialog boxes with specific instructions
- **Multiple Input Types**: Keyboard presses, mouse clicks, drag operations, and typing
- **Sequential Execution**: Each successful action briefly pauses or extends the countdown timer
- **Escalating Complexity**: Commands become more demanding as pressure increases

### Command Variety

#### Keyboard Actions
- **Key Smashing**: Rapidly hit specific keys (e.g., "SMASH ESC!")
- **Word Typing**: Quick entry of abort codes (e.g., "TYPE 'ABORT'!")
- **Key Combinations**: Multi-key sequences for complex commands
- **Rapid Sequences**: Consecutive different keys in specific order

#### Mouse Operations
- **Target Clicking**: Precise clicks on moving or fading "OK" buttons
- **Right-Click Actions**: Context menu operations under pressure
- **Drag Operations**: Quick window repositioning to designated spots
- **Multi-Click**: Rapid successive clicks on specific targets

#### Interface Manipulation
- **Window Dragging**: Move dialog boxes to precise locations
- **Menu Navigation**: Quick access to specific menu options
- **Icon Selection**: Rapid clicking on correct desktop icons
- **Scroll Operations**: Quick scrolling to specific document positions

## Pressure Escalation

### Environmental Chaos
- **System Instability**: Windows flicker and error messages cascade
- **Audio Intensity**: Frantic beeping and alarm sounds build tension
- **Visual Distortion**: Screen elements shake, flash, and distort
- **Time Pressure**: Large countdown timer dominates the interface

### Command Complexity Progression
1. **Simple Commands**: Basic single-key presses or clicks
2. **Compound Actions**: Multi-step operations requiring sequence memory
3. **Precision Tasks**: Exact positioning or timing-sensitive operations
4. **Chaos Navigation**: Commands that appear amid visual chaos and distractions

### Failure Accumulation
- **Fatal Errors**: "Fatal Error!" pop-ups consume precious countdown time
- **Missed Commands**: Failed actions result in time penalties
- **Cascading Failures**: Multiple mistakes compound pressure and difficulty
- **System Degradation**: Interface becomes increasingly unstable with errors

## Difficulty Scaling

### Tutorial Introduction
- **Single Commands**: One action type at a time for learning
- **Clear Instructions**: Obvious, well-highlighted command requirements
- **Generous Timing**: Ample time to read and execute commands
- **Forgiving Failures**: Minimal penalties for learning mistakes

### Standard Pressure
- **Mixed Commands**: Various input types in random sequence
- **Moderate Speed**: Reasonable time limits with building urgency
- **Clear Interface**: Commands visible despite mild visual effects
- **Standard Penalties**: Appropriate consequences for failures

### Maximum Crisis
- **Rapid Succession**: Commands appear in quick sequence with minimal gaps
- **Extreme Speed**: Very limited time for command recognition and execution
- **Chaotic Interface**: Severe visual distortion and interference effects
- **Harsh Penalties**: Significant time loss for any mistakes or delays

## Command Examples

### Basic Level Commands
- **"SMASH ESC!"**: Rapidly press Escape key multiple times
- **"CLICK OK!"**: Find and click the OK button in dialog box
- **"TYPE 'STOP'!"**: Quickly enter the word in text field
- **"RIGHT CLICK!"**: Perform right-click on specific target

### Intermediate Challenges
- **"DRAG WINDOW TO TOP-RIGHT!"**: Move dialog box to screen corner
- **"DOUBLE-CLICK DESKTOP!"**: Rapid double-click on empty desktop area
- **"PRESS CTRL+ALT+DELETE!"**: Execute three-key combination
- **"SCROLL DOWN TO BOTTOM!"**: Navigate to end of document quickly

### Advanced Crisis Commands
- **"TYPE PASSWORD BACKWARDS!"**: Enter specific text in reverse
- **"CLICK ALL RED BUTTONS!"**: Multiple rapid clicks on colored targets
- **"DRAG TO COORDINATES 150,200!"**: Precise positioning requirement
- **"ALTERNATE LEFT-RIGHT CLICKS!"**: Complex clicking pattern

## Success Conditions

### Victory Requirements
- **Complete Sequence**: Successfully execute all required commands
- **Timer Survival**: Finish before countdown reaches zero
- **Error Tolerance**: Maintain performance despite some mistakes
- **Final Confirmation**: System stabilization and wipe cancellation

### Performance Evaluation
- **Response Speed**: Average time between command appearance and execution
- **Accuracy Rate**: Percentage of commands executed correctly on first attempt
- **Pressure Handling**: Performance maintenance under maximum stress
- **Recovery Ability**: Bounce back from errors and continue effectively

## Strategy Guide

### Preparation Techniques
- **Mental Readiness**: Prepare for rapid command recognition and execution
- **Hand Positioning**: Optimal keyboard and mouse placement for quick access
- **Focus Training**: Ability to concentrate despite visual and audio chaos
- **Command Familiarity**: Practice with various input types and combinations

### Execution Strategies
- **Read Fast**: Quickly scan commands for key action words
- **Prioritize Accuracy**: Better to be slightly slower than make errors
- **Stay Calm**: Maintain composure despite escalating chaos and pressure
- **Muscle Memory**: Develop automatic responses for common command types

### Recovery Tactics
- **Quick Reset**: Don't dwell on mistakes; immediately focus on next command
- **Time Management**: Balance speed with accuracy to maintain timer buffer
- **Chaos Navigation**: Filter important information from visual/audio chaos
- **Endurance Pacing**: Maintain energy and focus throughout entire sequence

- **Reverse Psychology**: Commands that require opposite actions
- **Multi-Tasking**: Simultaneous commands requiring parallel execution

### Expert Techniques

- **Predictive Reading**: Anticipate command types based on patterns
- **Rapid Switching**: Seamlessly transition between input methods
