# Brute Force Alphabets Mini-Game

## Overview
The Brute Force Alphabets mini-game simulates the rapid iteration of characters during a password brute force attack. Players must demonstrate quick reflexes and precision to crack password sequences by matching rapidly cycling characters.

## Gameplay Mechanics

### Visual Interface
- **Password Slots**: Series of empty slots representing the target password (e.g., "_ _ _ _ _")
- **Character Cycling**: Rapidly flashing sequence of alphabet letters, numbers, and symbols below each slot
- **Progress Indicator**: Shows which character position is currently active

### Core Mechanics
1. **Character Matching**: Wait for the correct character to appear in the cycling sequence
2. **Timing**: Click or press the corresponding key when the target character flashes
3. **Sequential Progression**: Each successful match locks in a character and moves to the next slot
4. **Speed Increase**: Cycling speed increases with each successful character match

### Success Conditions
- **Perfect Match**: Successfully identify and select all characters in the password
- **Time Bonus**: Faster completion yields higher scores
- **Accuracy Reward**: Fewer mistakes result in better performance ratings

### Failure States
- **Character Mismatch**: Selecting wrong character triggers "hash mismatch" pop-up
- **Time Penalty**: Mistakes result in brief time delays or character scrambling
- **Sequence Reset**: Multiple failures may reset current progress

## Difficulty Scaling

### Beginner Level
- **Password Length**: 3-4 characters
- **Character Set**: Lowercase letters only
- **Cycling Speed**: Slow, predictable timing
- **Retry Attempts**: Unlimited with minimal penalties

### Intermediate Level
- **Password Length**: 5-6 characters
- **Character Set**: Mixed case letters and numbers
- **Cycling Speed**: Moderate pace with slight acceleration
- **Visual Noise**: Occasional false characters or distractors

### Advanced Level
- **Password Length**: 7-8 characters
- **Character Set**: Full alphanumeric plus special symbols
- **Cycling Speed**: Rapid pace with significant acceleration
- **Time Pressure**: Limited time window for each character selection
- **Pattern Complexity**: May include similar-looking characters (0 vs O, 1 vs l)

## Technical Implementation

### Input Methods
- **Mouse Clicking**: Click on the cycling character when it matches target
- **Keyboard Input**: Press the key corresponding to the target character
- **Touch Interface**: Tap on mobile devices for character selection

### Audio Feedback
- **Success Sound**: Satisfying "click" or "beep" for correct matches
- **Error Sound**: Jarring buzz or static for incorrect selections
- **Progress Audio**: Building musical tension as password completion approaches

### Visual Effects
- **Character Lock Animation**: Satisfying visual confirmation when character is secured
- **Scramble Effect**: Brief visual chaos when mistakes occur
- **Success Celebration**: Triumphant "Access Granted!" pop-up with classic Win95 styling

## Scoring System

### Performance Metrics
- **Completion Time**: Faster cracking yields higher scores
- **Accuracy Rate**: Percentage of correct character selections
- **Streak Bonus**: Consecutive successful matches without errors
- **Difficulty Multiplier**: Higher difficulty levels provide score bonuses

### Ranking Categories
- **Script Kiddie**: Basic completion with multiple errors
- **Junior Hacker**: Decent performance with few mistakes
- **Elite Cracker**: Near-perfect execution with minimal errors
- **Legendary**: Flawless performance under maximum difficulty

## Tips & Strategies

### Focus Techniques
- **Peripheral Vision**: Watch multiple character positions simultaneously
- **Rhythm Method**: Develop internal timing for character cycling patterns
- **Pattern Recognition**: Learn common password structures and character combinations

### Error Recovery
- **Stay Calm**: Don't let mistakes disrupt your rhythm
- **Quick Recovery**: Rapidly refocus after scramble effects
- **Strategic Timing**: Wait for clear character visibility before attempting selection

### Advanced Tactics
- **Predictive Selection**: Anticipate likely characters based on password context
- **Speed Optimization**: Balance accuracy with completion time for optimal scores
- **Muscle Memory**: Develop quick reflexes for common character combinations
