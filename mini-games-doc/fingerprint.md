# Fingerprint Hack Mini-Game

## Overview
The Fingerprint Hack mini-game simulates bypassing a high-security biometric lock by reconstructing a complete fingerprint pattern from fragmented pieces. Players must demonstrate visual puzzle-solving skills and spatial reasoning under intense time pressure.

## Gameplay Mechanics

### Biometric Interface
- **Fragmented Display**: Partially visible fingerprint pattern as foundation
- **Segment Pieces**: Various fingerprint fragments scattered around the interface
- **Assembly Area**: Central reconstruction zone for building complete pattern
- **Pattern Matching**: Precise alignment required for successful biometric bypass

### Core Reconstruction Process
1. **Pattern Analysis**: Study the existing fingerprint base structure
2. **Piece Identification**: Examine available fragments for potential matches
3. **Spatial Positioning**: Drag and drop segments to appropriate locations
4. **Rotation Adjustment**: Rotate pieces to match ridge flow and orientation
5. **Final Verification**: Complete pattern must pass biometric authentication

### Fragment Manipulation
- **Drag-and-Drop**: Move fingerprint segments to assembly area
- **Rotation Control**: Adjust piece orientation to match ridge patterns
- **Snap Alignment**: Automatic fine-tuning when pieces are close to correct position
- **Pattern Flow**: Ridge lines must connect seamlessly between segments

## Security Pressure Elements

### Attempt Limitation
- **Three-Strike System**: Maximum of 3 attempts before lockout
- **Countdown Warning**: Visual indicators showing remaining attempts
- **Escalating Tension**: Increasingly urgent audio and visual warnings
- **Final Attempt Pressure**: Maximum stress on last chance

### Time Constraints
- **Rapid Assembly**: Limited time window for complete reconstruction
- **Segment Timeout**: Individual pieces may expire if not placed quickly
- **Countdown Timer**: Visible time remaining for current attempt
- **Pressure Building**: Audio and visual intensity increases with urgency

### Failure Consequences
- **Biometric Mismatch**: Error message for incorrect pattern assembly
- **Attempt Deduction**: Loss of one of three available tries
- **Pattern Reset**: Fragments return to starting positions
- **Security Escalation**: Increased difficulty on subsequent attempts

## Pattern Recognition Skills

### Ridge Analysis Techniques
- **Flow Direction**: Understanding natural fingerprint ridge patterns
- **Connection Points**: Identifying where fragments should align
- **Curve Matching**: Recognizing curved ridge structures across pieces
- **Termination Points**: Finding where ridges naturally end or bifurcate

### Spatial Reasoning
- **Orientation Logic**: Understanding how pieces should be rotated
- **Negative Space**: Using gaps to determine correct fragment placement
- **Symmetry Recognition**: Identifying balanced patterns in fingerprint structure
- **Scale Consistency**: Ensuring fragment sizes match the base pattern

### Problem-Solving Strategies
- **Perimeter First**: Start with edge pieces to establish boundaries
- **Distinctive Features**: Focus on unique ridge patterns for easier identification
- **Process of Elimination**: Rule out obviously incorrect placements
